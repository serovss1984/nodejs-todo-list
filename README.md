# Node.js To-Do List

Простой веб-сайт для управления списком задач.

## Стек

- Node.js
- Express
- SQLite
- better-sqlite3
- EJS
- HTML5 / CSS3

## Возможности

- Добавление новых задач
- Отметка задач как выполненных
- Удаление задач
- Сохранение задач в SQLite
- Сохранение данных после перезагрузки страницы

## Установка

Клонировать репозиторий:
